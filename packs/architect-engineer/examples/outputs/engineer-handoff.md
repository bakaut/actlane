# Engineer Handoff

## Goal

Implement the approved architecture work from the architect output.

## Inputs

- Facts, assumptions, decisions, risks, and open questions from architect mode.
- Boundaries, contracts, flow, and risk analysis.
- Durable decision Markdown refs.
- MCP summary refs.

## Rules

- Do not implement unresolved open questions.
- Do not change architecture boundaries without explicit confirmation.
- Keep implementation scoped to the handoff.
