# Actlane Packs

Packs are portable bundles of agent capabilities, policies, target adapters, examples, and generated artifacts.

Status: Phase 0 RFC. Packs in this repository are hand-written examples, not generated by a production CLI yet.

## Packs

- [safe-gitops](safe-gitops/README.md) - safe AI-assisted GitHub workflows.
- [architect-engineer](architect-engineer/README.md) - Codex architect mode that prepares engineer handoffs.
