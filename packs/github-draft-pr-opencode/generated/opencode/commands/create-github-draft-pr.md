# create-github-draft-pr

Generated by Actlane from pack github-draft-pr-opencode and capability create-github-draft-pr.

Use this OpenCode command when changes have already been reviewed and the user asks to prepare a GitHub draft pull request.

## Required Flow

1. Inspect git status and changed files.
2. Refuse secret, credential, token, and private-key paths.
3. Refuse unreviewed or excessive file sets.
4. Run the configured test command when present.
5. Ask for explicit confirmation before creating a branch, commit, or pull request.
6. Create a branch with prefix actlane/.
7. Commit reviewed files only.
8. Create the GitHub pull request with draft=true.
9. Return PR URL, branch, files, test status, and policy decision.

## Inputs

- `baseBranch` (string, required)
- `branch` (string, required)
- `confirmed` (boolean, required)
- `files` (array, required)
- `repo` (string, required)
- `summary` (string, required)
- `title` (string, required)

## Reporting

- Include changed files.
- Include policy decision.
- Include draft PR URL when created.
