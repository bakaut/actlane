# safe-gitops Agent Instructions

Use this pack for safe AI-assisted GitHub workflows.

## create-safe-draft-pr

Use `create-safe-draft-pr` only when the user explicitly asks to prepare a draft pull request.

Rules:

- Do not edit secrets or credentials.
- Keep PRs as draft.
- Use branch prefix `actlane/`.
- Summarize changed files and policy decisions.
- Ask for explicit confirmation before mutating repository state.
