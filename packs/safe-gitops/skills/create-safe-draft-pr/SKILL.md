# create-safe-draft-pr

Use this skill when the user wants an AI-assisted draft pull request prepared safely.

## Rules

- Confirm before mutating repository state.
- Never include secret or credential files.
- Keep the pull request as draft.
- Use branch prefix `actlane/`.
- Run project tests when the project has a known safe test command.
- Report changed files, policy decisions, and the final PR URL.

## Workflow

1. Load repository context.
2. Review requested changes and file list.
3. Apply policy checks.
4. Mutate safe defaults such as branch prefix and `draft: true`.
5. Ask for explicit confirmation if the action is mutating.
6. Create branch, commit files, and create draft PR.
7. Return concise summary and audit-friendly details.

This is a Phase 0 example skill. It is not generated by a production CLI yet.
