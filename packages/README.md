# Actlane Packages

This directory contains the working Actlane CLI MVP plus placeholders for later package boundaries.

## Planned Boundaries

- [cli](cli/README.md) - working Go CLI MVP for the OpenCode target.
- [generator](generator/README.md) - deterministic artifact generation, currently implemented inside `cli/internal/generator`.
- [policy](policy/README.md) - local policy evaluation, planned for Phase 4.
- [runtime](runtime/README.md) - optional enforcement runtime, planned for Phase 5.
- [sdk](sdk/README.md) - library APIs, future phase.
