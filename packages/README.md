# Actlane Packages

Phase 0 placeholder directory.

There is no production implementation yet. These package directories document intended boundaries for later phases only.

## Planned Boundaries

- [cli](cli/README.md) - command-line entry point, planned for Phase 1.
- [generator](generator/README.md) - deterministic artifact generation, planned for Phase 1.
- [policy](policy/README.md) - local policy evaluation, planned for Phase 4.
- [runtime](runtime/README.md) - optional enforcement runtime, planned for Phase 5.
- [sdk](sdk/README.md) - library APIs, future phase.
